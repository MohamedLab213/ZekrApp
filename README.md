# تطبيق ذكر (ZekrApp) 🌙

تطبيق بسيط وخفيف لنظام التشغيل Windows يقوم بإظهار نافذة تذكير بذكر الله كل 5 دقائق.

## ✨ المميزات
- **بسيط وخفيف:** لا يستهلك موارد الجهاز ولا يتطلب أي تثبيت.
- **واجهة جذابة:** تصميم أنيق يظهر في الزاوية السفلية من الشاشة.
- **يعمل في الخلفية:** يستخدم `VBScript` للعمل في الخلفية بصمت.
- **عدم المقاطعة:** يظهر فوق النوافذ ويختفي تلقائياً بعد 30 ثانية.

## 🚀 طريقة الاستخدام
1. قم بتحميل ملفات المشروع.
2. انقر نقراً مزدوجاً على الملف `Boucle.vbs`.
3. سيعمل البرنامج في الخلفية وستظهر نافذة التذكير كل 5 دقائق.

## 🛠️ التقنيات المستخدمة
- **HTA (HTML Application):** لبناء واجهة المستخدم باستخدام HTML و CSS.
- **VBScript:** لإنشاء حلقة التكرار وتشغيل النافذة في الخلفية.
- **PowerShell:** لضمان ظهور النافذة فوق جميع التطبيقات الأخرى.
